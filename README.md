# perm-monitor

Сбор данных с открытого API и поиск новых записей по фильтру региона.

## Файлы

| Файл | Назначение |
|---|---|
| `monitor_perm.py` | Скрипт. Стандартная библиотека Python, внешних пакетов нет. |
| `found_objects.txt` | Журнал: дата, метка (`базовая линия` / `НОВЫЙ`), данные записи. |
| `seen_ids.json` | Уже обработанные ID. Не удалять. |
| `heartbeat.txt` | Суточная отметка; держит расписание включённым. |
| `.github/workflows/monitor.yml` | Расписание и сохранение состояния. |

## Запуск

~~~bash
python3 monitor_perm.py           # полный проход
python3 monitor_perm.py --quick   # только свежие записи
./check.sh                        # прогон + последние 5 строк журнала
~~~

## Расписание

- `*/5 * * * *` — быстрый режим, 3 страницы API; если появилось новое, скрипт сам
  делает полный проход.
- `12 3 * * *` — полный проход раз в сутки.
- Состояние коммитится после прогона; раз в сутки дописывается `heartbeat.txt`.
- Уведомления — в Telegram, если заданы секреты `TG_TOKEN` и `TG_CHAT_ID`.
